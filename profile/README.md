## What we build

- **Websites & web apps** - fast, clean, built from scratch, no bloated templates.
- **Discord bots** - trading systems, VM control panels, status monitors, community tools.
- **SaaS & client work** - dashboards, billing, API integrations (Stripe, Xero, Steam and more).
- **Game & desktop tooling** - including [UmbraflowDG](https://github.com/umbraflow-co/UmbraflowDG), our Fluent dark theme for Discord and Garry's Mod.

## Our stack

We're not a one-trick shop. Between the two of us we cover the full spread: frontend, backend, bots, infra, automation and game modding.

**Languages** - TypeScript and JavaScript day to day, plus Python, C#, C++, Java, Go, PHP, Lua and shell scripting where the job calls for it. Whatever the project speaks, we speak.

**Frontend** - [Next.js](https://nextjs.org) and React with Tailwind CSS, plus plain HTML/CSS/JS when a site doesn't need a framework. Dark, clean, fast; built from scratch, no page builders.

**Backend** - Node.js APIs and services with [Prisma](https://prisma.io) or Sequelize on PostgreSQL, MySQL or SQLite. Auth with NextAuth, validation with Zod, email with Nodemailer.

**Bots & realtime** - [discord.js](https://discord.js.org) bots with voice calling, music playback, canvas-rendered images and full database-backed trading economies. WebSockets and browser-based remote desktop (noVNC / Guacamole) for our VM portal.

**Integrations & AI** - Stripe, Xero, Steam, Discord, Google and OpenAI APIs, webhooks, OAuth/OpenID sign-in, and OCR with Tesseract. If it has an API, we've probably wired it up.

**Media & tooling** - image processing with sharp and canvas, audio pipelines with FFmpeg and Lavalink, plus scrapers, monitors and desktop automation scripts.

**Infra** - Docker everywhere, running on our own dedicated servers with [OVH](https://www.ovhcloud.com) and [BinaryLane](https://www.binarylane.com.au). Deployed through Coolify onto Proxmox virtual machines, which we also control through our own Discord bots.
